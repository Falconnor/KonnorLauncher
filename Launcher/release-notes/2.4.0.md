# Konnor Launcher 2.4.0

## Hosting de terceros
- La pestaña **Crear servidor** del Hosting pasa a llamarse **Terceros**: gestiona desde el launcher los servidores que tienes en otros hostings.
- **exaroton:** conecta tu cuenta con un token de la API y controla tus servidores sin salir del launcher. Puedes encenderlos, apagarlos y reiniciarlos, ver los jugadores conectados y usar la consola con comandos.
- **Aternos, Hostinger, Modrinth Servers** y cualquier otro **panel web:** se abren dentro del launcher. La sesión se guarda cifrada en tu equipo, así que no tienes que iniciar sesión cada vez.
- Cada hosting aparece con **su propio icono**. Haz clic en la fila para entrar directamente.
- El token de exaroton se guarda cifrado con tu usuario de Windows.

## Instancias sincronizadas
- El punto del icono muestra si **el servidor está encendido** (verde) o **apagado** (rojo). Se comprueba cada minuto.
- Cuando hay una **actualización** del servidor, el icono de la instancia aparece con un **marco amarillo**.
